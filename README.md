## Selected work

- **Sign2Speak** - Fully on-device American Sign Language → speech translator.
  MediaPipe landmarks → Conv1D+Transformer classifier → Gemma cascade → TTS, on Android.
  Built at the Google DeepMind Gemma hackathon.
- **Explainable deep-RL for insulin delivery** (esieaLab) - making a SAC control policy
  interpretable through causal / anti-causal inference. Ongoing research.
- **Clinical ML - hormonotherapy toxicity prediction** - 1-year toxicity prediction on a
  de-identified breast-cancer cohort (missing-data mechanism, missForest vs MICE).
- **Loodo** - productivity app with an LLM coaching agent; prototyped an on-device coach
  by fine-tuning Mistral 7B (QLoRA / Unsloth).
